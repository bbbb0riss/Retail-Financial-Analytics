# Бизнес-задача

## Описание компании

TechStore — федеральная сеть магазинов электроники, осуществляющая продажи через розничные магазины и интернет-платформу.

## Цель проекта

Провести анализ продаж и финансовых показателей компании за 2025 год для выявления факторов, влияющих на прибыльность бизнеса.

## Задачи

- определить наиболее прибыльные категории товаров;
- выявить ключевых клиентов;
- проанализировать динамику продаж;
- оценить эффективность магазинов;
- подготовить рекомендации по повышению финансовых показателей.

## Ожидаемый результат

По итогам анализа должны быть подготовлены SQL-запросы, интерактивный дашборд Power BI и рекомендации для руководства компании.

Расширение аудитории
Проведен анализ продаж розничной сети TechStore за 2025 год. Выявлена сильная зависимость от Москвы (32% продаж), низкая маржинальность в отдельных категориях и отсутствие данных о клиентах. Предложены меры по увеличению среднего чека, развитию регионов и внедрению CRM-системы. При реализации рекомендаций прогнозируется рост выручки на 25-30% в течение года.
