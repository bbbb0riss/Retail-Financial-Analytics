# Retail-Financial-Analytics
Аналитический кейс по исследованию продаж и финансовых показателей розничной сети. Проект включает проектирование базы данных, SQL-анализ, визуализацию в Power BI и подготовку бизнес-рекомендаций на основе полученных результатов. 
Руководство компании TechStore хочет оценить эффективность продаж и финансовые результаты за 2025 год.

Необходимо:

- определить наиболее прибыльные категории товаров;
- выявить ключевых клиентов;
- проанализировать динамику продаж;
- оценить эффективность магазинов;
- подготовить рекомендации по увеличению прибыли.
